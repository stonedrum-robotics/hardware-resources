# Hardware integration reference material

Preliminary notes and resource placeholders for planning component integration.

| Path | Current contents |
|---|---|
| `cad/mounting-brackets/` | Placeholder README; no qualified bracket design |
| `wiring/interface-boards/` | Reference notes; no validated interface-board design |
| `bom/accessories-bom.csv` | Preliminary accessory list; confirm exact parts for a selected configuration |
| `integration-guides/` | Robot-arm integration notes requiring source, version and engineering review |

These materials are starting points for investigation. They do not establish mechanical fit, wiring safety, arm compatibility, regulatory conformity or manufacturing readiness. Any physical installation needs configuration-specific engineering and safety review.
